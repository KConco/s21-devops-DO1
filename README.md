# Проект D01: Основы администрирования Linux

Этот проект посвящен изучению базовых концепций и утилит операционной системы Linux. В ходе выполнения заданий были освоены ключевые навыки, необходимые для администрирования сервера на базе Ubuntu 20.04 LTS.

## 🚀 Освоенные темы и навыки

### 1. Установка и базовая настройка ОС
- **Установка Ubuntu Server 20.04 LTS** в виртуальной среде (VirtualBox) без графического интерфейса.
- **Настройка сети:**
  - Работа с DHCP для автоматического получения IP-адреса.
  - Настройка статического IP-адреса, маски подсети, шлюза (gateway) и DNS-серверов.
  - Определение внешнего и внутреннего IP-адресов.
- **Настройка системного времени** и часового пояса, включая синхронизацию через NTP.

### 2. Управление пользователями
- Создание новых пользователей и управление ими.
- Добавление пользователей в группы (`adm`).
- Настройка прав доступа с помощью `sudo` для выполнения команд от имени суперпользователя.

### 3. Работа с пакетами
- **Обновление системы** и установленных пакетов с использованием менеджера пакетов `apt`.

### 4. Системные службы
- **Настройка службы времени (NTP)** для автоматической синхронизации времени.
- **Установка и настройка SSH-сервера (`sshd`)**:
  - Изменение стандартного порта для повышения безопасности.
  - Настройка автоматического запуска службы при старте системы.

### 5. Работа в командной строке
- **Текстовые редакторы:**
  - **Vim, Nano:** создание, редактирование, сохранение и закрытие файлов.
  - Продвинутые функции: поиск по тексту и замена слов.
- **Мониторинг системы:**
  - **`top`**: анализ загрузки CPU и использования памяти, определение `uptime` и количества запущенных процессов.
  - **`htop`**: интерактивный мониторинг процессов с сортировкой и фильтрацией.
- **Работа с дисковой подсистемой:**
  - **`fdisk`**: просмотр информации о дисках и разделах.
  - **`df`**: анализ использования дискового пространства файловыми системами.
  - **`du`**: оценка размера файлов и директорий.
  - **`ncdu`**: интерактивный анализ использования диска.

### 6. Анализ системных журналов
- Просмотр и анализ лог-файлов (`/var/log/dmesg`, `/var/log/syslog`, `/var/log/auth.log`).
- Поиск информации о событиях в системе, таких как авторизация пользователей или перезапуск служб.

### 7. Автоматизация задач
- **Планировщик `cron`**: создание, просмотр и удаление заданий для автоматического выполнения команд по расписанию.
